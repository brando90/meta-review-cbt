# experiments

Analyses of **published** data only (no patient data). Candidate analyses:

1. **Effect-size drift.** Extract effect sizes and publication years from the CBT meta-analyses in `deep-research/` and fit a simple meta-regression of effect size on year, with control type as a covariate.
2. **Moderator scan.** Tabulate which published CBT trials report executive-function or ADHD moderators, and test whether those effects are consistently in one direction.
3. **Power check.** Compute the sample size needed to detect a plausible executive-function moderator effect in a CBT trial (prediction P1 in the paper).

Every analysis: a script in this folder, a dated entry in `LOG.md` (question, data source and DOI, code path, result, caveats). Nothing here has been run yet.
