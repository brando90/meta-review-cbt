# deep-research

Literature search for the review. Draft 1 uses the 20 sources in `references.bib` (all DOI-verified). Draft 2 adds a deep pass over four slices, one notes file each in `sources/`:

1. `efficacy.md`: CBT efficacy meta-analyses, effect-size decline over time, bias and control-group effects, head-to-head comparisons.
2. `mechanisms.md`: dismantling and component studies, exposure and inhibitory learning, third-wave alternatives.
3. `ef.md`: executive function, stress, emotion regulation and reappraisal; executive function as a moderator of CBT outcome.
4. `adhd.md`: CBT, medication and mindfulness for adult ADHD; anxiety-ADHD comorbidity.

See `protocol.md` for how sources are found and verified, and `VERIFICATION.md` for the log.
